# ホテル情報の登録

Hotel Post AI を最大限に活用するためには、まずあなたのホテル情報を正しく登録することが重要です。
ここで登録した情報をもとに、AIがあなたのホテルらしさを反映した記事を作成します。

## 登録手順

1. **メニューから「ホテル登録」を選択**
   ダッシュボードのメニューにある「ホテル登録」をクリックします。

2. **基本情報の入力**
   以下の情報を入力してください。
   - **ホテル名**: 正式名称を入力してください（例：ホテル・ポスト・イン東京）。
   
   ※ 現在、登録機能はシンプルですが、内部的には登録されたホテルIDに紐づく詳細情報（特徴、ターゲット層など）を管理できるようになっています。

3. **登録ボタンをクリック**
   入力内容を確認し、「登録」ボタンを押します。

> [!TIP]
> **ポイント**: ホテル情報は一度登録すれば、毎回入力する必要はありません。AIが常にこの情報を参照して記事を書きます。

## 次のステップ

ホテル情報の登録ができたら、いよいよ[記事の作成](post-generation.md)に進みましょう！
