# Hotel Post AI とは？

**「記事作成にかかる時間を、もっとお客様のための時間へ。」**

Hotel Post AI は、ホテルの魅力を伝えるブログやSNS（Instagram, Xなど）の投稿文を、AIが自動で作成してくれるサービスです。

## ✨ こんなことができます

- **ブログ記事の自動作成**:
  季節のイベントやホテルの特別なプランに合わせたブログ記事を、数クリックで作成できます。
- **SNS投稿文の作成**:
  InstagramやX（旧Twitter）など、各SNSに最適な長さやトーンで文章を作成します。
- **多言語対応のサポート** (※将来的な機能):
  海外のお客様向けに、英語や中国語での発信もお手伝いします。

## 🚀 導入のメリット

1. **時間短縮**: これまで1時間かかっていた記事作成が、数分で完了します。
2. **クオリティの安定**: 文章が苦手なスタッフでも、プロのような魅力的な文章を作成できます。
3. **発信頻度の向上**: 手軽に作れるから、毎日の発信も苦になりません。

## 🔄 ご利用の流れ

基本的な使い方はとてもシンプルです。

1. **ホテル情報を登録する**: 最初に一度だけ、あなたのホテルの特徴を登録します。
2. **テーマを選ぶ**: 「春のランチフェア」「クリスマスディナー」など、書きたいテーマを入力します。
3. **AIが作成**: ボタンを押すと、AIが数秒で記事を書き上げます。
4. **確認・投稿**: 内容を確認して、微調整したらSNSやブログに投稿完了！
