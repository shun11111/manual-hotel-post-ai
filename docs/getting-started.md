# スタートガイド

## 1. アカウント作成とログイン

まずはじめに、アカウントを作成しましょう。

1. **登録画面へアクセス**: トップページの「新規登録」ボタンをクリックします。
2. **情報の入力**: メールアドレスとパスワードを入力します。
3. **確認メール**: 登録したメールアドレスに確認コードが届きますので、画面に入力してください。
4. **ログイン**: 登録が完了したら、メールアドレスとパスワードでログインします。

## 2. ダッシュボードの見方

ログインすると、ダッシュボードが表示されます。

- **ホーム**: 新しい記事を作成するためのメニューがあります。
- **履歴**: 過去に作成した記事の一覧を確認・修正できます。
- **ポイント残高**: 今月使える記事作成ポイントが表示されます。

## 3. 「ポイント」について

Hotel Post AI では、記事を作成するたびに「ポイント」を使用します。

- **毎月付与**: 毎月1日に、無料ポイントが付与されます。
- **消費量**: 記事の長さや生成するモデルによって消費ポイントが異なります（例：ブログ記事 1回 5pt）。
- **確認方法**: 画面右上のアイコンから、現在の残りポイントをいつでも確認できます。

次は、[ホテル情報の登録](hotel-registration.md)を行いましょう。
