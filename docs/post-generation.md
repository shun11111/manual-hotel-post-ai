# 記事を作成する

Hotel Post AI のメイン機能である、記事作成の手順を説明します。

## 作成手順

1. **画面の選択**
   ダッシュボードから「新規作成」を選びます。

2. **テーマの入力**
   何についての記事を書きたいか、短い文章で入力してください。
   > **例**: 「春限定の桜ディナーコースの案内」「週末の空室わずかのお知らせ」「地元の花火大会の紹介」

3. **投稿タイプの選択 (Type)**
   どの媒体に投稿するかを選びます。媒体に合わせて文章の長さや口調が最適化されます。
   - **Blog**: ブログ用（長文、詳細な説明）
   - **Twitter**: X用（短文、ハッシュタグのみ）
   - **Instagram**: インスタグラム用（絵文字多め、ハッシュタグ多め）
   - **Facebook**: フェイスブック用（丁寧な挨拶、程よい長さ）

4. **AIモデルの選択 (AI Model)**
   使用するAIの種類を選びます。モデルによって消費ポイントと文章の質が異なります。
   - **GPT-4o mini (2pt)**: バランス型。普段の投稿におすすめ。
   - **Claude 3.5 Sonnet (8pt)**: 自然で人間らしい文章が得意。
   - **GPT-4o (10pt)**: 最も高性能。重要な告知などに。
   - **Claude 3 Haiku (1pt)**: 高速・低コスト。簡単な挨拶などに。

5. **作成ボタン (Generate)**
   「Generate」ボタンを押すと、数秒〜数十秒で記事が作成されます。

## 下書きの確認と編集

作成された文章は画面に表示されます。
そのままコピーして投稿することもできますが、**必ず人の目で内容を確認してください**。
AIは時々、架空の情報（存在しないメニューや日付など）を書くことがあります。必要に応じて修正してから投稿してください。

## 履歴の確認

作成した記事はシステムに保存され、「履歴」メニューからいつでも見返すことができます。
